# Harbor Transfer Portal v1.0.2 — negative rollback acceptance candidate

**Status: TEST ONLY — intentionally unhealthy — never deploy.**

This candidate exists solely to exercise the Windows PowerShell upgrade rollback path after a healthy v1.0.1 installation.

## Candidate identity

- Product version: 1.0.2
- Architecture: build-time amd64/arm64, must match the installed 1.0.1 kit
- OCI image version/revision labels: generated by the standard release image builder from this exact source revision
- Offline kit: generated by the standard checksummed offline-kit builder

## Intentional failure

The backend healthcheck in this candidate's `deploy/offline/compose.yaml` is deliberately configured to exit non-zero. The image itself remains correctly versioned. The candidate must fail Compose readiness during upgrade, causing `upgrade.ps1` to restore the pre-upgrade v1.0.1 backup and report `ROLLBACK_OK`.

## Safety

Use only on a disposable Windows VM after successfully installing and verifying the healthy v1.0.1 acceptance candidate. Do not run `install.ps1` or `install.cmd` from this negative kit as a standalone install. Do not merge, tag, publish or deploy it. Preserve both kits and the backup if rollback reports `ROLLBACK_FAILED`.
